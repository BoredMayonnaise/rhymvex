## How to Use This Directory

Each phase file contains:
- **Goals** — what success looks like at the end of the phase
- **Key tasks** — broken into workstreams (Brand, Content, Business Dev, Tech)
- **Deliverables** — concrete outputs and assets
- **KPIs** — measurable signals of completion
- **Timeline** — estimated duration and milestones

Update each file as work progresses. Check off tasks, log notes, and move to the next phase only when KPIs are met.
